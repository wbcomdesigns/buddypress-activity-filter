# Requirements

**Included in Free**

| Requirement | Version |
| --- | --- |
| WordPress | 6.9 or higher |
| PHP | 8.1 or higher |
| BuddyPress | 12.0.0 or higher, with the Activity component active |
| Tested up to | WordPress 7.1 |

## Not supported

BuddyBoss. It has similar built-in activity filtering, so the plugin shows an admin notice and does not run when BuddyBoss is detected.

## Multisite

The plugin header allows network activation. Settings are stored per site as normal WordPress options.
